# Квадрат



В табличку на гугл тейблс записались студенты, увы некоторые не смогли разобраться и записались несколько раз. Организаторам нужно узнать, сколько в списке разных участников.

## Задача

В списке могут встречаться повторяющиеся имена. Определите количество уникальных участников.

Логику подсчёта необходимо вынести в отдельный модуль. В отдельном модуле реализуйте публичную функцию:

```rust
pub fn unique_count(names: &[String]) -> usize
```

Используйте эту функцию в основном файле программы.

## Рекомендации

- Перед началом работы самостоятельно создайте Rust-проект в этой папке командой `cargo init --name task3_3_template`.
- Разместите функцию в модуле `participants` (`src/participants.rs`) и объявите его публичным в `src/lib.rs` с помощью `pub mod participants;`. Используйте функцию из основного файла программы.
- Проверьте работу функции на пустом списке, на списке без повторов и на списке с повторяющимися именами.
- Автоматические тесты находятся в `tests/assignment.rs`; запускайте их командой `cargo test`.
- После реализации запустите `cargo fmt` и `cargo check`.
